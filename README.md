# TaskBridge — MVP маркетплейса digital-услуг

TaskBridge (Биржа задач) — маркетплейс, где заказчики публикуют digital-задачи, а исполнители откликаются и выполняют их. Проект предназначен для проверки гипотезы: малому бизнесу нужен простой сервис для поиска исполнителей на небольшие технические и маркетинговые задачи.

## Роли

- **Заказчик** — публикует задачи, выбирает исполнителя, общается в чате, оставляет отзывы.
- **Исполнитель** — ищет задачи, отправляет отклики, выполняет работу, получает отзывы.
- **Администратор** — управляет пользователями и задачами, рассматривает жалобы, просматривает статистику.

## Быстрый старт

```bash
# 1. Установить зависимости
npm install

# 2. Заполнить демо-данными (создаёт пользователей, задачи, отклики, чаты и отзывы)
npm run seed

# 3. Запустить сервер
npm start
```

Сервер будет доступен по адресу **http://localhost:3000**.

## API-эндпоинты

### Аутентификация
- `POST /api/auth/register` — регистрация (выбор роли: client/performer)
- `POST /api/auth/login` — вход, возвращает JWT

### Задачи
- `GET /api/tasks` — список задач с фильтрами и поиском
- `GET /api/tasks/:id` — детали задачи
- `POST /api/tasks` — создать задачу (только заказчик)
- `PUT /api/tasks/:id/choose` — выбрать исполнителя
- `PUT /api/tasks/:id/status` — сменить статус задачи
- `GET /api/tasks/categories` — список категорий

### Отклики
- `POST /api/tasks/:id/offers` — отправить отклик (только исполнитель)
- `GET /api/tasks/:id/offers` — список откликов на задачу
- `GET /api/offers/my` — мои отклики (исполнитель)

### Чат
- `GET /api/tasks/:id/chat` — сообщения по задаче
- `POST /api/tasks/:id/chat` — отправить сообщение
- `GET /api/chat/list` — список активных чатов

### Отзывы
- `POST /api/reviews` — оставить отзыв (после завершения задачи)
- `GET /api/reviews/user/:id` — отзывы пользователя

### Уведомления
- `GET /api/notifications` — список уведомлений
- `GET /api/notifications/unseen-count` — количество непрочитанных

### Жалобы
- `POST /api/reports` — подать жалобу

### Админка (только admin)
- `GET /api/admin/stats` — статистика
- `GET /api/admin/users` — список пользователей
- `PATCH /api/admin/users/:id` — заблокировать/разблокировать
- `GET /api/admin/tasks` — все задачи
- `PATCH /api/admin/tasks/:id` — скрыть/показать задачу
- `GET /api/admin/reports` — список жалоб

### Пользователи
- `GET /api/users/:id` — профиль
- `PUT /api/users/profile` — обновить свой профиль
- `GET /api/users/performers/list` — список исполнителей

### Система
- `GET /api/health` — проверка работоспособности

## Тестирование

```bash
# Запустить тесты
npm test

# С покрытием
npm run test:coverage
```

Тесты покрывают: регистрацию, аутентификацию, CRUD задач, отклики, выбор исполнителя, чат, завершение задач, отзывы, админ-функции, уведомления и жалобы.

## Технологический стек

- **Backend:** Node.js 18+, Express.js
- **База данных:** SQLite (better-sqlite3)
- **Аутентификация:** JWT + bcrypt
- **Frontend:** Vanilla JS SPA + Tailwind CSS (CDN)
- **Тесты:** Jest + SuperTest

## Что не входит в MVP

- Реальная оплата и безопасная сделка
- Мобильное приложение
- Email/Telegram-уведомления
- Сложный арбитраж споров
- Многоязычность
- SEO-оптимизация

> В этой версии нет реальной оплаты. Сделки и деньги обсуждаются сторонами напрямую. Проект подготовлен как MVP для проверки механики маркетплейса.

## Деплой

Проект можно развернуть на любом хостинге с поддержкой Node.js:

```bash
# На сервере
git clone <repo>
npm install --production
npm run seed
npm start
```

Для production рекомендуется использовать PM2 или аналогичный process manager:

```bash
npx pm2 start server.js --name taskbridge
```
